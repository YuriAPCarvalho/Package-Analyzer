# Code Signing Policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

SignPath Foundation integration: planned / application pending.

## Source and build provenance

Official binaries are built from the public source code and build scripts maintained in this repository:

[github.com/YuriAPCarvalho/Package-Analyzer](https://github.com/YuriAPCarvalho/Package-Analyzer)

Release artifacts must be generated by the official GitHub Actions workflow from a tagged commit.

## Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or by the person installing or operating it.

See [PRIVACY.md](PRIVACY.md) for details.

## Release process

1. Changes are committed to the public source repository.
2. Build and tests are executed by GitHub Actions.
3. Release artifacts are generated from a versioned tag.
4. SHA-256 checksums are generated and published with the release.
5. A signing request will be submitted only after SignPath Foundation approval and CI integration.
6. The maintainer manually approves each signing request.
7. Signed artifacts are published on the official releases page after signing is active.

## Signing scope

Code signing is limited to official Package-Analyzer release artifacts produced by the release workflow.

Third-party components, including `trivy.exe`, remain the property of their respective authors and must not be rebranded or signed as original Package-Analyzer code.

## Current unsigned releases

Until SignPath Foundation approval is complete, releases are published unsigned with SHA-256 checksums and a SmartScreen notice.
